# Szerveroldali webprogramozás Laravel ZH minták

Ebben a repóban az ELTE Informatikai Karon oktatott szerveroldali webprogramozás tantárgy számonkéréseinek mintáját találhatjátok.

Mappaszerkezet:

- `1-zh`: a félév közepén írandó zárthelyi mintái, amelyek fókuszában a Laravel alapjai állnak teljes oldal generálási példákon.
- `2-zh`: a félév végén írandó zárhelyi mintái, amelyek fókuszában a REST API és GraphQL API fejlesztés áll.

**Figyelem!** Mivel a minták korábbi félévek zárthelyi feladatai alapján készültek, előfordulhat, hogy friss PHP verzió alatt figyelmeztetést (deprecation warning) vagy hibát adnak. Ettől függetlenül a feladat ugyanúgy felhasználható felkészülésre, az éles ZH-n olyan kezdőcsomagot biztosítunk, ami a laborgépeken aktuálisan megtalálható környezetben zavaró jelenségek nélkül fog működni.
